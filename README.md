# STAMP / QUEUE

Static browser game prototype. Open `index.html` through a web server so `data/gameData.json` can be fetched.

- Human + 3 AI
- Lines A–E
- 21 visible queue slots per line; waiting queue is not capped at FV
- Two-click Human line selection: preview, then confirm
- WAIT / STAY supported
- Random turn order each phase; AI acts after earlier choices
- Global line Reward capacity with simultaneous all-or-nothing reward handling
- Score tiers from gameData.json
- AI speed X1 / X2 / X4 and EASY / NORMAL / HARD
